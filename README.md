# HAND · FIELD

노트북/PC 웹캠으로 손을 인식해서 화면 속 파티클·버튼과 상호작용하는 TouchDesigner 스타일 로컬 웹앱.

## 실행
`start.bat` 더블클릭 (또는 `node server.js` → http://localhost:8790). 카메라 권한 허용.
라이브러리(three.js, MediaPipe)와 손 인식 모델은 `vendor/`에 들어 있어 인터넷 없이도 동작합니다.

## 제스처
| 제스처 | 01 PARTICLE TEXT | 02 FLOW FIELD | 03 POINT CLOUD |
|---|---|---|---|
| ✋ 펼친 손 | 휘저어 흩뜨리기 | 소용돌이 + 손끝에서 입자 방출 | 막(membrane) 누르기 |
| 🤏 핀치 | 블랙홀처럼 끌어당김 → 놓으면 폭발 | 〃 | 파문(ripple) |
| ✊ 주먹 | 글자 흩어짐 (펴면 복귀) | 시간 정지 | 쥐고 움직여 회전 |
| 🤏🤏 두 손 핀치 | 글자 크기·회전 | 손 사이 빛줄기 | 확대·회전 |
| ☝ 버튼 위 검지 | 0.85초 두면 클릭 (핀치하면 즉시 클릭) | | |

키보드: `1` `2` `3` 모드 · `H` UI 숨김 · `C` 카메라 패널 · `Space` 폭발. 카메라가 없으면 마우스로 조작(클릭=핀치).
